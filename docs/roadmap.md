# Roadmap

What was built, phase by phase, and the task IDs the source comments cite. A
`P6-24` or `E5-3` in a comment means a line below.

The working tracker these came from (`PLAN.html`, `PLAN-FEATURES.html`) is a
process document and is not part of this repository. What survives here is the
shape of the work and the identifiers the code refers to; the reasoning lives in
the [decision log](decisions.md).

Status is as of the last release. A box that is not ticked was either
dispositioned deliberately or is open work — see the decision log for which.
